# 生活垃圾焚烧发电厂运行管理平台

面向垃圾进厂计量、垃圾池管理、焚烧炉与余热锅炉运行、汽轮发电机组、烟气净化与在线排放监测、飞灰固化与炉渣处理、渗滤液处理、设备点检检修与值班交接的一体化生活垃圾焚烧发电厂运行管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `waste-to-energy-plant:entries` 这一项，或调用 `resetModule(模块)`。

## 在线排放监测（CEMS）归属与防篡改

CEMS 模块的业务规则集中在 `frontend/src/data/cems.ts`，页面读写走
`frontend/src/api/cems-service.ts`，页面组件不做业务判断：

- **归属定死**：每台采集设备（CEMS-A/B/C）固定挂在一个岗位名下，记录的归属岗位随登记时选用的
  采集设备写死。页头可切换岗位（烟气净化岗 / 总排口值守岗 / 第三方运维），第三方运维名下没有
  采集设备。
- **跨岗位改动打回**：非归属岗位的登记、编辑、审定、提交采集一律在服务层打回，并明确返回
  卡在哪一步（归属校验 / 锁定校验 / 字段只读校验 / 唯一校验 / 权限校验 / 状态校验 / 参数校验）。
- **固定字段只读**：监测编号、监测因子、排放限值、采集设备、归属岗位为定死字段，即使是归属岗位
  本人修改也会被「字段只读校验」挡下；归属岗位只能改实测值、折算值、采集时间、审核人员。
- **审定即锁定**：已审核记录整份锁住，归属岗位本人也不能再改，也不参与限值重算。
- **编号唯一**：同一监测编号重复登记在「唯一校验」打回。
- **拦截留痕**：所有被挡下的尝试写入 `waste-to-energy-plant:cems-deny-logs`，含操作人、岗位、
  时间、尝试动作、目标记录、卡在哪一步、原因，页面「拦截留痕」页签可倒查。
- **限值调整与重算**：限值带版本（`waste-to-energy-plant:cems-limits`）。调整后只重算已采集但
  未审定的记录，重算前后限值与超标结论差异留存于「重算差异」页签；结论翻转时同步更新环保监控
  预警台账。已审定记录按审定当时结论保留，仅在差异表标注「审定保留」。
- **预警台账回写**：超标结论以 `WARN-<监测编号>` 编号回写到 `emission` 模块（环保指标监控），
  结论翻转时同一条记录更新为「预警解除」，不会重复新增。
- **既有数据兼容**：老格式 CEMS 数据在首次打开时由 `ensureCemsMigrated()` 补齐归属设备/岗位、
  限值版本与超标判定；历史已审核记录直接锁定，结论不动。
